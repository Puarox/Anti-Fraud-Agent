# 作品集讲解与证据索引

本文帮助面试官和项目维护者从“问题—工程选择—验证—限制”理解仓库。它不替代阶段报告，也不把代码存在等同于个人原创。

## 90 秒讲述

诈骗线索通常散落在截图、录音、短视频和用户描述里。原型把媒体处理和高危规则留在确定性代码中，再将可追溯证据交给受限的调查 Agent。Agent 每次只能从符合当前输入条件的只读工具中选择下一步；新结果作为观察回到规划环。无法核实的网址返回 `UNKNOWN`，信息不足时暂停补问，用户补充后可沿案件 Checkpoint 继续。最后报告给出风险提示、证据编号、资料来源和不确定性，而非单句“真/假”。

## 值得讲的排障故事

基线代码把 GAANet 接到了“视频鉴诈”接口，但核对其模型仓库和任务后发现，它实际是音视频语音分离模型，不能支撑深伪识别宣传。因此旧入口改为明确拒绝该调用，再把来源凭证、媒体质量、AASIST 与 DFDS 标成各自有限的信号；缺权重或缺证据时返回不可用/未知。该处理优先保证演示不制造错误结论。详见[W0 基线记录](../reports/W0-baseline.md)与[W4 媒体取证记录](../reports/W4-media-forensics.md)。

另一个工程问题是长视频预处理会让浏览器请求等待过久；工作台改成异步案件任务并轮询状态，但队列当前仅在进程内存。详见[W5 集成记录](../reports/W5-integration-evaluation.md)。

## 仓库归属与个人表达

- 仓库记录表明 Flutter、React、Spring Boot、旧模型服务等模块来自原始压缩包中的既有项目源码；原始项目的成员分工、竞赛角色和获奖信息没有在本仓库提供证据，不据此推断个人贡献或团队奖项。
- W0–W6 是本仓库后续本地化改造的记录，可用 Git commit、代码、测试和截图逐项核对；不得将原系统全栈模块、团队奖项或未完成能力都包装成个人独立完成。
- 面试前应挑选自己实际负责且能现场解释的改造点，准备从问题、选型、失败样例到验证路径的完整说明。若使用 AI 编码辅助，应按实际情况说明其参与范围，并能独立解释关键实现与取舍。

## 公开展示时仍需保留的限制

1. 知识库规模小，检索收益尚未以独立数据集评估。
2. 6 个手写动作场景属于研发烟测，不能称为诈骗判断准确率或 Agent 提升。
3. AASIST / DFDS 只有未校准实验信号；GAANet 不承担深伪识别。
4. Web Job 不跨进程持久化，尚无多用户隔离和生产部署方案。
5. 本机脱敏并非完整隐私保护；公共服务化前必须补充保留期、访问控制、删除和隐私评测。
