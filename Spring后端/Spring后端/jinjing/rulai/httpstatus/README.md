# HTTP异常处理模块

全部的 `Exception` 均以 `BaseHTTPException` 为父类

> **MST**: 我不是很确定这种枚举类的方式进行编写是否合适，我这么做基于以下理由：
> 1. 不同状态码的异常类可能有一些细微的差别，例如 301 可能会包含新的 URL ，即便目前没有用到，现在先保留向后兼容的能力。
> 2. 不同状态码的异常处理可能会有细微不同。
> 3. 这样枚举类的方式，可以充分利用代码提示，类似于在编写逻辑的时候 throw new UnauthorizedException("登录过期")，代码自身会成为注释。

## 状态码：
 - 4** 实现了 400 ~ 410
 - 5** 实现了 500 ~ 505
