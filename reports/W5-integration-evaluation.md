# W5 集成与回归阶段报告（2026-10-26）

## 已交付

- Web 工作台用异步任务处理案件录入与 Agent 调查；浏览器轮询本机状态，不再等待一个长 HTTP 请求。任务单进程单 worker，仍只监听回环地址。
- 案件页面显示证据 ID、时间或画面框、规则命中、检索出处、媒体取证原始信号、Agent 假设/理由/工具回执。报告可下载 JSON，补充事实后旧报告返回 409，防止误用。
- 案件和报告增加 `schema_version=1.0`；[本机 API 契约](../docs/local_api_v1.md) 说明字段、异步任务和手机上传边界。
- Agent 规划输入现在包含工具观察摘要与新事实。新增 `REVIEW_FORENSICS` 只读工具；工具回执能够影响补问。跨轮 Checkpoint 保留历史，新事实到来时重置本轮工具预算；无新事实的重复运行直接返回原报告。
- 本地 0.5B 模型作为动作选择回退；完整安装的 1.5B 模型输出结构化动作、查询、假设和理由。两者都被白名单、URL 来源校验、PII 门禁和工具预算约束。

## 可复现验证

- 收窄已执行工具的动作白名单后，6 个手写动作情境中：固定流程的首步“总先检索”在 2/6 情境中属于预设可接受动作；Qwen2.5-0.5B 为 3/6（1 例输出已禁动作而失败）；Qwen2.5-1.5B 为 3/6。完整逐例结果见 `evaluation/comparison_qwen2.5-0.5b-instruct.json` 和 `evaluation/comparison_qwen2.5-1.5b-instruct.json`。这些是研发烟测，不代表真实案件准确率，也不能据此说较大模型一定更好。
- 1.5B 的失败样例：信息极少时过早检索、视频案件先补问而未利用现有媒体工具、音频检测已弃权时仍再次检索。最新单步冷启动 20.15 秒，其余示例 11.99–15.51 秒，因此调查入口改为异步。
- 真实本机模型完整轨迹最初出现 `SEARCH_KNOWLEDGE` 后重复检索两次，执行层均阻断。规划层排除已使用工具后，同一合成案件变为 `SEARCH_KNOWLEDGE → ASK_USER`，只有一条成功检索回执。这个修复减少无效调用，但仍需大样本验证补问是否恰当。
- Headless Edge 实际通过“输入含手机号文本 → 异步轮询 → 案件页”流程；页面显示 `[PHONE_1]`、`ev_001` 和 `CRITICAL`，没有脚本错误。[浏览器截图](w5-browser-evidence.png)。
- `python -m unittest discover -s tests -v` 最终 19 项全部通过；测试覆盖去敏、来源与检索、Agent 工具回路、媒体弃权、异步任务。最新浏览器烟测也通过，并重拍上述截图。

## 验收边界

本阶段完成了可重复运行的本机 Web 原型，**没有通过公共服务上线门槛**。6 个手写情境没有统计意义，尚缺至少 200 例独立人工标注案件、固定工作流与 Agent 在同工具同预算下的完整任务级盲测、深伪分域误报/漏报评估。检索只有 3 条人工核对的权威资料卡，不足以证明 RAG 较旧 Top-3 系统改善。手机端未对接；Web 是用户允许的调试替代。任务状态是单进程内存，服务重启后丢失；缺持久队列、取消、用户隔离和保留期清理。自动去敏可能漏掉姓名、侧脸或音频说出的身份信息，不能作为公网出端保证。

原始 RAR 中出现过的第三方凭据仍需要持有者在服务端轮换；工作区已移除硬编码。对于公众输出，当前仅给行为风险提醒和可复查证据，媒体真伪保持 `UNKNOWN`。
