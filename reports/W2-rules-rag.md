# W2：风险规则与来源可追溯检索

日期：2026-10-25。

## 已完成的可运行部分

- 从已核对的政府/监管部门公开提醒整理 3 条带来源、发布日期、审核日期和来源层级的本地知识卡片。原项目案例未获来源核验，因此暂未混入“权威”索引。
- 实现本机 BM25 + 中文 BGE 小模型向量召回、RRF 融合及精确关键词的轻量重排；缺少向量模型时可退化为 BM25。检索结果保存来源 URL、文档 ID、发布日期和两路分数。
- 新增安全账户转账、屏幕共享+凭据、刷单垫资、索要验证码等即时提示规则；命中关联输入证据 ID 和知识来源 ID。无规则命中返回 `UNKNOWN`，不返回“安全”。
- 本地网址初检只做 URL 解析与精确官方域名比对；形似域名不会被误认。未接实时网址信誉库时明确返回 `UNKNOWN`。
- 建立外部文本出端门禁：需要明确同意和人工/用户隐私复核，出端载荷只有经规则检测的脱敏文字和证据 ID，不附媒体。
- Web 工作台显示风险信号、官方资料与网址初检。

## 验证

- 10 项离线测试全部通过，覆盖规则证据引用、无命中不判安全、官方域名防混淆、出端门禁和 W0/W1 回归。
- “公检法要求转安全账户并开启屏幕共享”样例命中 `CRITICAL` 规则，能回到输入证据；混合检索返回来源可查的政府提醒。
- 本地使用 `BAAI/bge-small-zh-v1.5`，模型文件位于工作区 `models/` 并被 `.gitignore` 排除。

## 未通过的完整阶段门槛

- 知识库目前只有 3 条人工核对的种子卡片，尚无正式文档切分、动态更新/失效复核和规模化标注检索集；不能据此宣称检索质量优于原 Top-3。
- 轻量重排不是独立交叉编码器；原版云端向量检索也因缺少 Qwen 凭据无法做同条件评测。
- 没有授权的实时信誉服务或号码/账户风险库。网址工具只能给已维护的官方域名线索和 `UNKNOWN`，不能证明未知网址安全或危险。
- 中文规则去敏仍可能漏姓名、地址、声纹和 OCR 错字；即使出端门禁允许，真实外部服务接入前仍需补脱敏评测与授权界面。
