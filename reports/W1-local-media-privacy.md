# W1：本地媒体与隐私基础记录

日期：2026-10-25。

## 已完成

- 新增独立本机 Web 工作台 `local_web.py`，仅监听 `127.0.0.1:5050`；支持文本、图片、音频、视频上传与案件查看。
- 建立案件目录、媒体 SHA-256、证据文字/时间戳/画面框坐标与本地预览。视频按 5 秒间隔取帧，演示版限制 10 分钟、最多 40 帧。
- 本地 RapidOCR 识别截图/视频帧文字，OpenCV 解二维码；同一案件用稳定占位符遮挡手机号、身份证、账号、邮箱、验证码。
- 预览重编码并遮挡识别出的敏感文字、整个二维码；用 OpenCV 正脸检测对命中的面部做模糊。原件与取证帧仅保存在本机案件目录。
- 下载并在本机加载 `Systran/faster-whisper-base`（`model.bin` SHA-256：`D01C3014881C9C6F3133C182F3D2887EB6CA1C789A7538C5C007196857A0A6A9`）；语音经 FFmpeg 提取后离线转写。模型缺失时明示 `UNAVAILABLE`，不自动上传云端。
- 新增 `requirements-local.txt`、本地启动说明、隐私与 OCR 的离线测试。

## 验证

- 6 项 `unittest` 通过，覆盖旧 API、文字脱敏、截图 OCR 位置与遮挡、ASR 不可用状态。
- 合成中文语音在本机 ASR 返回片段；合成视频同时返回带位置的 OCR 与 ASR，二维码样本返回经遮挡的收款账号。未对真实用户媒体做外部传输。
- 本机工作台 `GET /` 可返回页面，上传结果可通过案件页面与 JSON 接口查看。

## 局限与 W2 输入

- Whisper Base 在合成中文句子中把“验证码”误识为相近词，不能把转写当作无误原话；应让用户可回放音频并在风险规则里处理近似说法。
- 目前去敏只覆盖可规则识别的字段和正面人脸；姓名、地址、侧脸、OCR 漏字及音频声纹仍可能留下敏感信息。因此预览仅供本机调试，**不得直接用于云端发送或对外分享**。
- 当前没有诈骗判定、知识检索或 Agent；W2 将加入风险规则、证据检索与出端门禁。
- 媒体处理仍是同步请求，长视频的异步任务/进度和失败恢复留到 W3/W5。
