# W9：案件处置工具扩展

## 目标

这轮把工具扩展到线索核验之后的实际处置环节：本地预检网址、可选外部沙箱、建立人工复核工单、搜索本机历史相关视频，以及在指定目录上运行持续守护进程。

## 新增能力

### URL 本地预检与沙箱

Agent 的 `CHECK_URL` 仍只检查案件中实际出现的 URL。现在会附加本地静态预检结果，包括 IP 字面量、Punycode、内嵌凭据、异常端口和敏感查询参数。它不会请求目标网站，所以它不是动态沙箱，也不会据此给出安全结论。

案件页面另有 urlscan.io 私有扫描入口。用户必须点击并在浏览器弹窗确认，服务器还会验证 URL 属于当前案件；仅发送 `visibility=private` 的请求，并对已识别的 PII 作拦截。urlscan 的远程浏览器会访问目标站，因此请求可能产生站点侧日志或触发 GET 页面行为。只有配置 `URLSCAN_API_KEY` 才能提交。Private 代表服务端访问范围更窄，不代表数据仍留在本机。

urlscan 官方文档说明扫描提交需要 API key，并允许 `public`、`unlisted`、`private` 三种可见性：[Scanning API](https://docs.urlscan.io/apis/urlscan-openapi/scanning)、[Scan Visibility](https://docs.urlscan.io/pages/visibility)。项目固定 private，但外送动作仍由用户单独确认。

### 人工复核工单

工单保存在案件目录下的 `review_queue.sqlite`。字段包含案件 ID、优先级、原因、证据编号、状态、时间和复核意见；同一案件最多复用一个未关闭工单。高/严重规则命中或媒体真实性不明时，Agent 可以选择建立工单；用户也可以在案件页手动建立。首页提供队列入口，支持开始复核和完成复核。

工单状态代表队列流转，不代表模型完成了人工复核。复核人应填写自己的判断和后续处置；此原型尚无登录鉴权、多人权限和远程派单。

### 本机历史视频检索

`FIND_RELATED_VIDEOS` 只遍历本地案件清单，不上传视频。先比较媒体 SHA-256 找到完全相同的文件，再对案件已有 OCR/ASR 文本做字符二元组重叠召回。结果包含候选案件、命中证据编号、相似度和召回依据，便于回看原始材料。

文本相似只适合候选召回：同一话术不代表同一个视频，抽帧稀疏或 ASR 缺失也会漏召回。当前不做全网视频搜索、感知哈希或跨平台人脸检索。

### 实时本地守护进程

通过 `python -m jinjing.guardian --watch-dir <路径>` 显式启动。它只轮询这个目录的第一层文件；支持项目已接收的图片、音频和视频扩展名。文件连续两次轮询大小与修改时间不变后，创建案件并运行现有 Agent；是否建立复核工单由 Agent 根据观察和工具能力决定，不在守护进程工作流里固定调用。成功文件移入 `_jinjing_processed`，失败文件移入 `_jinjing_failed`。Ctrl+C 停止。

这不是系统级常驻服务，也不监控剪贴板、浏览器、短信、麦克风或目录之外的数据。文件内容仍留本机。当前依赖文件轮询，目录规模很大时不适合生产环境。

## Agent 运行时变化

- 工具从手写 `if/elif` 分支改为 `InvestigationTool` 注册表：每个工具单独声明可用条件、执行处理器、副作用和轨迹摘要；执行节点统一分发，支持通过构造器注入自定义工具。
- 案件录入不再自动调用 RAG 或 URL 核验；输入解析和风险规则保留为必要的确定性前置。Agent 的 SEARCH_KNOWLEDGE 与 CHECK_URL 成为实际按需工具。
- AIGC/来源/媒体质量取证也移到 `REVIEW_FORENSICS` 工具执行；OCR、ASR 和隐私预处理继续在录入阶段运行，为 Agent 提供基础观察。Agent 可先取证，再按结果决定是否建立复核工单。
- 可用动作从 9 项扩展到 11 项：本机相关视频检索、建立复核工单加入规划循环。
- 每轮预算由 6 提高到 8，仍然有界。URL 外送扫描刻意没有注册为 Agent 动作，避免规划器在没有用户确认的情况下发出数据。
- Web 工具目录现有 28 项能力，其中自动处理组件与 Agent 动作不等价；列表按实际入口区分。
- 新工具观察保留来源、状态、耗时、关联证据和限制。创建工单这种本地写入会被记作工具副作用。

## 检查范围

`python -m unittest discover -s tests` 全部 24 项通过，其中新增 3 项覆盖动态工具注册与派发、未注册动作拒绝、入案时 RAG/URL 不自动执行；既有媒体入案测试也确认 AIGC/来源分析保持待 Agent 调用。另通过 Python 编译、JavaScript 语法、Jinja 模板编译、Markdown 本地链接和 `git diff --check`。外部沙箱需要密钥及用户当次确认；没有提交真实案件 URL。守护进程和工单流转未作生产级验证。
